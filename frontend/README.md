# 前端说明

前端使用原生 HTML、CSS 和 JavaScript 编写，不依赖 Vue、React、Vite 等框架。页面通过 `fetch` 调用 Flask API，实现单张增强、批量增强、局部对比图展示和结果下载。

## 启动方式

```bash
cd frontend
python -m http.server 5500
```

前端地址：`http://127.0.0.1:5500`

使用前请确保后端已启动：`http://127.0.0.1:5000`

## 页面功能

- 单张图片增强
- 批量图片增强
- 使用说明
- 原图与增强图展示
- 局部细节对比图展示
- 单张结果下载
- 批量结果打包下载

## 使用流程

### 单张图片增强

1. 上传一张图片。
2. 设置模型、放大倍数、去噪强度和分块大小。
3. 点击“开始增强”。
4. 查看原图、增强图和局部对比图。
5. 下载增强结果和局部对比图。

### 批量图片增强

1. 一次选择多张图片。
2. 在文件列表中查看文件名和大小，并按需移除。
3. 设置批量参数。
4. 点击“开始批量增强”。
5. 查看每张图片的结果卡片。
6. 下载单张结果或打包下载全部结果。

## 常见问题

- 如果页面提示后端不可用，请先确认 `python app.py` 是否已启动。
- 如果图片无法显示，请检查浏览器是否能够访问后端接口地址。
- 如果批量处理中部分图片失败，页面会在对应卡片中显示失败原因，不会影响其他图片继续处理。
